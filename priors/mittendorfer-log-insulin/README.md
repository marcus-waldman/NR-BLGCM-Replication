# Empirical Priors for Legendre Coefficients — Log-Insulin (Pregnancy)

## Overview

This folder contains the source data and audit script used to derive empirical priors for the **P1–P4 Legendre polynomial coefficients** of the OGTT log-insulin trajectory at pregnancy timepoints (baseline 31 wk, post-intervention 36 wk). The priors are emitted at brm() runtime by `R/prior_specification.R::derive_legendre_priors_from_csv()`, which reads `mittendorfer_ogtt_insulin_reference v2.csv` directly. The script here reproduces the same fit and writes inspectable audit artifacts.

The intercept P0 receives a data-scaled diffuse prior (`Normal(0, 10·sd(y)·κ)`) elsewhere in `prior_specification.R` and is not handled by these empirical priors.

## Source

**Citation**: Mittendorfer, B., et al. (2023). [Full citation TBD — see project Zotero collection `NR-BLGCM`]

**Figure**: Panel C of Figure 1 — 75 g OGTT plasma insulin trajectories, GDM and No-GDM at 35 weeks gestation. (The journal figure itself is not redistributed here; consult the cited article.)

## Data extraction (v2)

Two independent human raters visually digitized Panel C at 0, 10, 20, 30, 60, 90, and 120 min. Both rater readings are preserved as separate rows in `mittendorfer_ogtt_insulin_reference v2.csv` rather than averaged, so digitization uncertainty propagates into the prior through the lm standard error.

**Scope**: v2 retains only the 35-week groups (GDM 35 wk, No-GDM 35 wk). The 15-week groups previously used in v1 are not part of this derivation, because the analytic sample of the parent study (ME-BLOOD) is measured at 31 and 36 weeks gestation — the 35 wk groups are the closer biological match.

**`mittendorfer_ogtt_insulin_reference v2.csv` columns**:

| Column | Meaning |
|---|---|
| `time_min` | Time relative to OGTT load (min) |
| `rater` | `rater_1` or `rater_2` — preserved per row |
| `no_gdm_35wk` | Plasma insulin (mU/L), No-GDM group at 35 wk |
| `gdm_35wk` | Plasma insulin (mU/L), GDM group at 35 wk |

## Method

For each group (GDM 35 wk, No-GDM 35 wk):

1. Restrict to `time_min ∈ [0, 120]` (matches the ME-BLOOD OGTT window).
2. Map time to Legendre domain: `t_scaled = time_min / 60 − 1`.
3. Log-transform insulin: `log_value = log(value)`.
4. **Stack both raters' rows** as independent observations and fit ordinary least squares:
   ```
   log_value ~ P0 + P1 + P2 + P3 + P4 − 1
   ```
   The lm standard error on each coefficient (`se_gdm`) therefore captures rater / digitization noise.

Standard Legendre basis (P₀=1, P₁=x, P₂=(3x²−1)/2, P₃=(5x³−3x)/2, P₄=(35x⁴−30x²+3)/8) is applied to `t_scaled`.

## Prior construction

GDM-centered with prior SD combining rater noise and group spread in quadrature (parallel to the glucose priors):

- `prior_mean = coef_gdm`
- `prior_sd   = sqrt(se_gdm² + ((coef_gdm − coef_no_gdm)/1.5)²)`

Both `_ctrl` and `_treat` arms receive the same prior (the external source does not distinguish treatment arms). The prior is identical across the two pregnancy timepoints (`loginsulin0`, `loginsulin1`).

## Resulting priors (κ = 1)

P1–P4 only; P0 is data-scaled in `create_joined_growth_curve_priors_n()`.

| Term | GDM | No GDM | Prior Mean | Prior SD |
|------|------|--------|------------|----------|
| P1 | 0.77 | 0.49 | 0.77 | 0.20 |
| P2 | −0.65 | −0.85 | −0.65 | 0.16 |
| P3 | 0.44 | 0.43 | 0.44 | 0.07 |
| P4 | −0.29 | 0.06 | −0.29 | 0.25 |

Full-precision coefficients (with SEs and group_spread) are written to `legendre_coefficients_mittendorfer_insulin_pregnancy.csv` by the fit script.

## Reproduce

From the project root:

```bash
Rscript priors/mittendorfer-log-insulin/fit_legendre_to_mittendorfer_insulin.R
```

This regenerates the coefficient CSVs and the figure. The runtime priors used by the brm() model are obtained directly from the v2 CSV through `prior_specification.R` and do not depend on running this script.

## Scope

These priors are applicable **only to pregnancy timepoints** in this repository (baseline 31 wk, post-intervention 36 wk). Postpartum priors are not used in this codebase; the previously-included Zhang 2020 postpartum derivation has been removed.

## κ (prior sensitivity)

`create_joined_growth_curve_priors_n()` accepts a `prior_sd_scale` argument (denoted κ in the supplement) that multiplies every prior SD while leaving prior means untouched. Sensitivity refits in `main.R` use κ ∈ {1, 10, 100}. The S2 Figure 2 visualisation shows prior-draw spaghetti at each κ.
