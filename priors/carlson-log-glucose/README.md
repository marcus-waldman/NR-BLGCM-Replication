# Empirical Priors for Legendre Coefficients — Log-Glucose (Pregnancy)

## Overview

This folder contains the source data and audit script used to derive empirical priors for the **P1–P4 Legendre polynomial coefficients** of the OGTT log-glucose trajectory at pregnancy timepoints (baseline 31 wk, post-intervention 36 wk). The priors are emitted at brm() runtime by `R/prior_specification.R::derive_legendre_priors_from_csv()`, which reads `external_ogtt_glucose_reference v2.csv` directly. The script here reproduces the same fit and writes inspectable audit artifacts.

The intercept P0 receives a data-scaled diffuse prior (`Normal(0, 10·sd(y)·κ)`) elsewhere in `prior_specification.R` and is not handled by these empirical priors.

## Data extraction (v2)

Two independent human raters visually digitized Panel A at 10-minute intervals (−10 … 130 min). Both rater readings are preserved as separate columns in `external_ogtt_glucose_reference v2.csv` rather than averaged, so digitization uncertainty propagates into the prior through the lm standard error.

**`external_ogtt_glucose_reference v2.csv` columns**:

| Column | Meaning |
|---|---|
| `time_min` | Time relative to OGTT load (min) |
| `gdm_my_estimate`, `gdm_other_estimate` | Rater 1 and rater 2 readings, GDM group |
| `gdm_avg` | Per-time-point average (kept for reference; not used in fit) |
| `no_gdm_my_estimate`, `no_gdm_other_estimate` | Rater 1 and rater 2 readings, No-GDM group |
| `no_gdm_avg` | Per-time-point average (kept for reference; not used in fit) |

## Method

For each group (GDM, No-GDM):

1. Restrict to `time_min ∈ [0, 120]` (matches the ME-BLOOD OGTT window).
2. Map time to Legendre domain: `t_scaled = time_min / 60 − 1`.
3. Log-transform glucose: `log_value = log(value)`.
4. **Stack both raters' rows** as independent observations and fit ordinary least squares:
   ```
   log_value ~ P0 + P1 + P2 + P3 + P4 − 1
   ```
   The lm standard error on each coefficient (`se_gdm`) therefore captures rater / digitization noise.

Standard Legendre basis (P₀=1, P₁=x, P₂=(3x²−1)/2, P₃=(5x³−3x)/2, P₄=(35x⁴−30x²+3)/8) is applied to `t_scaled`.

## Prior construction

The runtime priors are **GDM-centered** with prior SD combining rater noise and group spread in quadrature:

- `prior_mean = coef_gdm`
- `prior_sd   = sqrt(se_gdm² + ((coef_gdm − coef_no_gdm)/1.5)²)`

The `/1.5` factor preserves the original "No-GDM within ~1.5 SD of GDM" coverage rule; the `sqrt(SE² + …)` enrichment adds rater noise.

Both `_ctrl` and `_treat` arms receive the same prior (the external source does not distinguish treatment arms). The prior is identical across the two pregnancy timepoints (`logglucose0`, `logglucose1`).

## Resulting priors (κ = 1)

P1–P4 only; P0 is data-scaled in `create_joined_growth_curve_priors_n()`.

| Term | GDM | No GDM | Prior Mean | Prior SD |
|------|------|--------|------------|----------|
| P1 | 0.33 | 0.21 | 0.33 | 0.08 |
| P2 | −0.38 | −0.31 | −0.38 | 0.05 |
| P3 | −0.01 | 0.03 | −0.01 | 0.03 |
| P4 | 0.12 | 0.10 | 0.12 | 0.02 |

Full-precision coefficients (with SEs and group_spread) are written to `legendre_coefficients_external_ogtt.csv` by the fit script.

## Reproduce

From the project root:

```bash
Rscript priors/carlson-log-glucose/fit_legendre_to_external_ogtt.R
```

This regenerates the coefficient CSVs and the figure. The runtime priors used by the brm() model are obtained directly from the v2 CSV through `prior_specification.R` and do not depend on running this script.

## Scope

These priors are applicable **only to pregnancy timepoints** in this repository (baseline 31 wk, post-intervention 36 wk). Postpartum priors are not used in this codebase; the previously-included Zhang 2020 postpartum derivation has been removed.

## κ (prior sensitivity)

`create_joined_growth_curve_priors_n()` accepts a `prior_sd_scale` argument (denoted κ in the supplement) that multiplies every prior SD while leaving prior means untouched. Sensitivity refits in `main.R` use κ ∈ {1, 10, 100}. The S2 Figure 1 visualisation shows prior-draw spaghetti at each κ.
